# Online Courses Platform

A full-stack learning platform with authentication, courses, quizzes, and instructor booking.

---

## 🚀 Live Demo

Frontend:
https://online-cousres.vercel.app/dashboard

Backend:
https://online-cousres.onrender.com

---

## 🧱 Tech Stack

Frontend:
- React
- TypeScript
- TailwindCSS
- Axios

Backend:
- Node.js
- Express
- Prisma ORM

Database:
- PostgreSQL (Neon)

Auth:
- JWT
